Providers, filters, formatters, tools and modes are all registered by name — swapping a teacher or an export format is a one-line config change.

Three distillation modes

data

Response distillation

A teacher generates synthetic responses; they are filtered, de-duplicated and formatted into fine-tuning data.

  • composable filters
  • exact + MinHash dedupe
  • chat / alpaca / sharegpt / text
agent

Agent distillation

A tool-using teacher agent solves tasks; every trajectory (reasoning, tool calls, results) is captured and scored.

  • tool registry + agent loop
  • behaviour cloning / SFT export
  • success-rate verification
logits

Classic KD

A student matches a white-box teacher's temperature-scaled token distribution, with vocabulary alignment.

  • Hinton loss, α and T
  • LoRA / 4-bit support
  • automatic vocab mapping
